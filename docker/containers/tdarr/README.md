# Tdarr One Flow Setup

## Configuring Radarr and Sonarr

1. Import [Radarr Custom Formats](Radarr_Custom_Formats) and [Sonarr Custom Formats](Sonarr_Custom_Formats)
2. For each Radarr and Sonarr instance Edit Quality Profile
   - Edit Custom Format 'AV1' score to `1`
   - Edit Custom Format 'HD Bluray - Compressed' score to `1801`
   - Edit Custom Format 'WEB - Compressed' score to `1701`
   - Save
